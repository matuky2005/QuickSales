# Zombie Plague Web — demo pública para iPhone

Este directorio contiene un prototipo estático **sin Counter-Strike**: portada y prueba interactiva de controles en horizontal para Chrome en iOS. No contiene software ni recursos de Valve.

## Publicar con GitHub Pages

En este repositorio, abrir **Settings → Pages**. Seleccionar **Deploy from a branch**, branch **zombie-plague-pages**, carpeta **/docs**. Guardar. Enlace esperado una vez publicado: https://matuky2005.github.io/QuickSales/ y la demo: https://matuky2005.github.io/QuickSales/demo/?touch=1

**No modificar main:** es una rama de pruebas aislada para no alterar el proyecto QuickSales. Al crear un repositorio específico, mover estos archivos a ese repositorio y cambiar la URL.

El motor Xash3D, el plugin Zombie Plague y el servidor de partidas aún no están instalados aquí. Para jugar de verdad se necesita alojar un servidor fuera de Pages y proporcionar los archivos legítimos de CS 1.6.
